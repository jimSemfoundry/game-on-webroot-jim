## 项目概述

GAME.ON 是一个现代化的在线游戏平台，提供赌场游戏、体育博彩等多种娱乐功能。项目采用 React 19 + TypeScript + Vite 构建，具备以下特性：

- 🎮 多游戏类型支持（Casino、Sports、Live Games）
- 🌍 45+ 语言国际化支持
- 🎨 动态主题系统
- 💰 多币种支持
- 📱 PWA 渐进式 Web 应用
- 🔐 完整的用户认证系统
- 🎁 丰富的奖励和促销系统

## 快速开始

### 环境要求

- **Node.js**: >= 18.0.0
- **pnpm**: >= 8.0.0 (推荐使用 pnpm)
- **操作系统**: macOS / Linux / Windows

### 安装依赖

```bash
# 使用 pnpm 安装（推荐）
pnpm install
```

### 开发服务器

```bash
# 启动开发服务器（端口 3000）
pnpm dev

# 或者使用
pnpm start
```

访问 http://localhost:3000 查看应用。

### 环境变量

创建 `.env` 文件（不要提交到 Git）：

```env
# API 基础地址
VITE_API_URL=https://api.example.com

# 其他配置
VITE_CHATWOOT_TOKEN=your_token_here
VITE_HCAPTCHA_SITE_KEY=your_key_here
```

**注意**: Vite 只会暴露以 `VITE_` 开头的环境变量给客户端代码。

### 构建生产版本

```bash
# 构建生产版本
pnpm build

# 预览生产构建
pnpm serve
```

构建输出位于 `dist/` 目录。

1. **组件文件**: PascalCase
   - ✅ `ReferralBanner.tsx`
   - ✅ `GameCard.tsx`
   - ❌ `referral-banner.tsx`

2. **Hooks 和工具**: camelCase
   - ✅ `useCredits.ts`

   - ✅ `bonus-banner.png`
   - ✅ `vip-level-1.png`

### 组件编写规范

```typescript
import { useState } from 'react';
import { useTranslation } from 'react-i18next';

interface GameCardProps {
  id: string;
  name: string;
  thumbnail: string;
  provider: string;
  onPlay: (id: string) => void;
}

export function GameCard({ id, name, thumbnail, provider, onPlay }: GameCardProps) {
  const { t } = useTranslation();
  const [isHovered, setIsHovered] = useState(false);

  return (
    <div
      className="relative rounded-lg overflow-hidden cursor-pointer"
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      onClick={() => onPlay(id)}
    >
      <img src={thumbnail} alt={name} className="w-full aspect-video object-cover" />
      {isHovered && (
        <div className="absolute inset-0 bg-black/60 flex items-center justify-center">
          <button className="btn btn-primary">{t('common.play')}</button>
        </div>
      )}
      <div className="p-3">
        <h3 className="font-semibold text-sm">{name}</h3>
        <p className="text-xs text-gray-500">{provider}</p>
      </div>
    </div>
  );
}
```

**要点**：
- 使用函数式组件和 Hooks
- Props 使用 TypeScript 接口定义
- 组件导出使用 named export
- 合理使用 Tailwind CSS 类名
- 国际化文本使用 `t()` 函数

**主要功能**：

**使用示例**：

```typescript
import { useAuth } from '@/contexts/AuthContext';

function ProfilePage() {
  const { user, isAuthenticated, login, logout } = useAuth();

  if (!isAuthenticated) {
    return <LoginPrompt />;
  }

  return (
    <div>
      <h1>Welcome, {user?.username}</h1>
      <button onClick={logout}>Logout</button>
    </div>
  );
}
```

**认证守卫**：

```typescript
// src/routes/_authenticated.tsx
export const Route = createFileRoute('/_authenticated')({
  beforeLoad: async ({ context, location }) => {
    const { isAuthenticated } = context.auth;
    if (!isAuthenticated) {
      throw redirect({
        to: '/',
        search: { redirect: location.href },
      });
    }
  },
});
```

### 4. 币种系统

支持 52+ 加密货币和法币，采用**结算币**和**显示币**分离的设计。

**核心概念**：
1. **结算币**: 用户实际充值、提现的货币（USDT、BTC、ETH、USD、CNY 等）
2. **显示币/游戏币**: 用户选择的显示和游戏单位（PHP、VND、USD 等）

**工作原理**：
- 用户选择 PHP 作为显示货币
- 充值的结算币（USDT、BTC 等）通过实时汇率自动转换成 PHP 显示
- 进入游戏时，所有金额都以 PHP 为单位计算
- 提现时再转换回对应的结算币

**核心 Context**：
- `DisplayCurrencyContext` - 管理显示货币/游戏货币（支持实时汇率和用户偏好）
- `SelectedCurrencyContext` - 管理选中的结算币种

**推荐使用方式**：

```typescript
import { useDisplayCurrency, useDisplayCurrencyFormatter } from '@/contexts/DisplayCurrencyContext';

function BalanceDisplay({ amount, currency }: { amount: number; currency: string }) {
  const { formatWithConversion, formatWithoutConversion, selectedCurrency } = useDisplayCurrencyFormatter();

  return (
    <div>
      <div>
        <span>显示币种: {selectedCurrency}</span>
      </div>
      
      <div>
        {formatWithConversion(amount, currency, { 
          showSymbol: true,
          minimizeDecimals: true 
        }).formatted}
      </div>
      
      <div className="text-sm text-gray-500">
        原始: {formatWithoutConversion(amount, currency, { 
          showSymbol: true 
        }).formatted}
      </div>
    </div>
  );
}

function CurrencySelector() {
  const { selectedCurrency, updateDisplayCurrency, groupedCurrencies } = useDisplayCurrency();

  const handleChange = async (newCurrency: string) => {
    try {
      await updateDisplayCurrency(newCurrency);
    } catch (error) {
      console.error('Failed to update currency:', error);
    }
  };

  return (
    <select value={selectedCurrency} onChange={(e) => handleChange(e.target.value)}>
      {groupedCurrencies.fiat.map((curr) => (
        <option key={curr.currency} value={curr.currency}>
          {curr.currency}
        </option>
      ))}
    </select>
  );
}
```

**重要特性**：
- ✅ 自动与登录用户的 `currency_fiat` 设置同步
- ✅ 支持 localStorage 持久化
- ✅ 实时汇率转换（通过 `useCurrencyData` hook）
- ✅ 本地更新 + 后端同步
- ✅ 智能回退（不支持的币种自动回退到 USD）

**注意事项**：
- `formatWithConversion`: 自动转换到用户选择的显示货币（推荐大部分 UI 使用）
- `formatWithoutConversion`: 只格式化原始货币，不进行转换
- 如需任意货币间转换，可直接使用 `useDisplayCurrency()` 中的 `convertCurrency` 函数
- 不建议直接使用 `utils/currency.ts`，因为它不包含实时汇率和用户偏好

### 7. 币种系统架构详解

项目采用 **双币种系统** + **三层管理架构**：

#### 双币种概念

```
1️⃣ 结算货币 (Settlement Currency)
   - Context: SettlementCurrencyContext
   - 用途：实际交易货币（充值、提现、下注）
   - 示例：USDT, BTC, ETH, USD, CNY
   - 用户字段：user.currency
   - 重要性：⭐⭐⭐⭐⭐ (核心)

2️⃣ 显示货币 (Display Currency)
   - Context: DisplayCurrencyContext
   - 用途：UI 显示单位（界面展示、游戏内显示）
   - 示例：PHP, VND, USD, THB, INR
   - 用户字段：user.currency_fiat
   - 重要性：⭐⭐⭐⭐ (用户体验)
```

**关键区别**：
- **结算货币** = 你的钱包实际存储的货币
- **显示货币** = UI 界面显示时转换成的货币

**示例**：
```
用户钱包: 100 USDT (结算货币)
用户偏好: PHP (显示货币)
汇率: 1 USDT = 56.5 PHP
界面显示: ₱5,650.00 PHP
```

#### 三层管理架构

```
1. 数据层: useCurrencyData (hooks/useCurrency.ts)
   ↓ 提供币种数据、汇率、基础格式化
   
2. 上下文层:
   - SettlementCurrencyContext (contexts/SettlementCurrencyContext.tsx)
   - DisplayCurrencyContext (contexts/DisplayCurrencyContext.tsx)
   ↓ 管理用户偏好、自动转换、持久化
   
3. 组件层: useDisplayCurrencyFormatter
   ↓ 提供便捷的格式化函数给 UI 组件
```

#### 完整数据流

```typescript
【交易流程 - 结算货币】
用户充值 100 USDT
    ↓
SettlementCurrencyContext 管理
    ↓
后端 API: POST /deposit { amount: 100, currency: "USDT" }
    ↓
用户钱包: user.balance = 100 USDT (user.currency = "USDT")

【显示流程 - 显示货币】
读取用户钱包: 100 USDT
    ↓
DisplayCurrencyContext 读取用户偏好 (currency_fiat: "PHP")
    ↓
查询实时汇率: 1 USDT = 56.5 PHP
    ↓
自动转换: 100 USDT × 56.5 = 5,650 PHP
    ↓
格式化显示: "₱5,650.00 PHP"
    ↓
UI 组件渲染
```

#### 持久化和同步

```typescript
本地偏好 (localStorage)
     ↕ 双向同步
用户登录状态 (user.currency_fiat)
     ↕ API 同步
后端用户设置
```

- **初始化**: localStorage → 浏览器检测 → 默认 USD
- **登录后**: 后端设置自动同步到前端
- **用户更改**: 前端立即更新 + 后端异步同步
- **智能回退**: 不支持的币种自动回退到 USD

#### 性能优化

1. **汇率缓存**: React Query 缓存汇率数据
2. **记忆化**: 格式化函数使用 useMemo
3. **按需加载**: 仅加载支持的币种
4. **防抖**: 用户快速切换时防止重复请求

#### 注意事项

⚠️ **不要这样做**:
```typescript
import { formatCurrency } from '@/utils/currency';
const formatted = formatCurrency(amount, currency);
```

✅ **应该这样做**:
```typescript
import { useDisplayCurrencyFormatter } from '@/contexts/DisplayCurrencyContext';
const { formatWithConversion } = useDisplayCurrencyFormatter();
const formatted = formatWithConversion(amount, currency).formatted;
```

**原因**: 
- `utils/currency.ts` 是静态工具，不包含实时汇率
- `DisplayCurrencyContext` 提供动态汇率和用户偏好
- 更好的类型安全和错误处理
- 自动与用户设置同步

import { gameService } from '@/services/gameService';

export function useGames(params?: GameParams) {

    },
  });
}

## 常见问题

### 1. 如何添加新的翻译语言？

1. 在 `public/locales/` 创建新语言文件夹（如 `ja/`）
2. 复制 `en/` 目录下所有 JSON 文件
3. 翻译所有文本
4. 语言会自动被 i18next 检测

### 2. 如何添加新的游戏提供商？

1. 在 `src/sections/casino/GameProviders.tsx` 添加提供商信息
2. 添加提供商 logo 到 `public/images/game/`
3. 更新类型定义

### 3. 如何自定义主题？

编辑 `public/theme-config.json`:

```json
{
  "currentTheme": "business",
  "customOverrides": {
    "colors": {
      "primary": "oklch(65% 0.25 270)",
      "secondary": "oklch(70% 0.15 180)"
    }
  }
}
```

运行 `pnpm theme:update` 应用更改。

### 4. 认证 Token 存储在哪里？

使用 `localStorage` 存储，位置：
- Key: 根据平台和用户信息生成
- 管理: `src/utils/auth.ts`

### 5. 如何处理 RTL（从右到左）语言？

项目支持 RTL 语言（如阿拉伯语、波斯语）：

1. RTL 自动检测基于语言
2. 样式: `src/styles/rtl.css`
3. Context: `src/contexts/RTLContext.tsx`

详见: `docs/RTL_GUIDE.md`

### 6. 如何优化动画性能？

项目使用 Motion (Framer Motion) 和 GSAP 进行动画处理。

**优化建议**：

1. **使用 CSS transforms 代替位置属性**
```typescript
<motion.div
  animate={{ scale: 1.2, opacity: 1 }}
  transition={{ duration: 0.3 }}
/>
```

2. **避免在动画中使用 layout 属性**（除非必要）
```typescript
<motion.div layout={false} />
```

3. **使用 will-change 提示浏览器**
```typescript
<motion.div
  style={{ willChange: 'transform' }}
  animate={{ x: 100 }}
/>
```

4. **对大量动画项使用虚拟化**
```typescript
import { Virtuoso } from 'react-virtuoso';

<Virtuoso
  data={items}
  itemContent={(index, item) => <AnimatedItem item={item} />}
/>
```

5. **使用 GSAP 的性能优化选项**
```typescript
import { gsap } from 'gsap';

gsap.to(element, {
  x: 100,
  duration: 0.5,
  force3D: true,
});
```

### 8. 币种格式化如何处理？

**推荐使用 `DisplayCurrencyContext`**（支持实时汇率和用户偏好）：

```typescript
import { useDisplayCurrencyFormatter } from '@/contexts/DisplayCurrencyContext';

function PriceDisplay() {
  const { formatWithConversion, formatWithoutConversion } = useDisplayCurrencyFormatter();

  const userBalance = 100;
  const balanceCurrency = 'USDT';

  return (
    <div>
      <div>
        {formatWithConversion(userBalance, balanceCurrency, {
          showSymbol: true,
          showCode: true,
          compact: false,
          minimizeDecimals: true,
        }).formatted}
      </div>
      
      <div className="text-xs">
        {formatWithoutConversion(userBalance, balanceCurrency, {
          showSymbol: true,
        }).formatted}
      </div>
    </div>
  );
}
```

**直接货币转换**（不依赖用户偏好）：

```typescript
import { useDisplayCurrency } from '@/contexts/DisplayCurrencyContext';

function CurrencyConverter() {
  const { convertCurrency, exchangeRates } = useDisplayCurrency();

  const convertedAmount = convertCurrency({
    amount: 100,
    fromCurrency: 'BTC',
    toCurrency: 'USD',
    exchangeRates,
  });

  return <div>{convertedAmount} USD</div>;
}
```

**选项说明**：
- `showSymbol`: 显示货币符号（如 $、₱、¥）
- `showCode`: 显示货币代码（如 USD、PHP、CNY）
- `compact`: 紧凑格式（如 1.2K、1.5M）
- `minimizeDecimals`: 智能最小化小数位（去除尾随零）

**注意**：避免直接使用 `utils/currency.ts`，因为它不支持实时汇率和用户偏好设置。
