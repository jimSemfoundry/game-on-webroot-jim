# 09 - 多品牌站点开站指南

本文档说明如何基于当前工程快速启用一个新的品牌站点，包含环境变量、主题资源与发布检查。

## 适用场景
- 新增独立品牌站点（不同域名、LOGO、主题、文案）
- 复用同一套代码与后端能力
- 需要在同一工程中维护多个站点

## 一、准备环境变量

复制 `.env.example` 为 `.env`，并设置以下关键字段：

```bash
VITE_API_URL=https://api.yourdomain.com/v1
VITE_IMAGE_URL=https://img.yourcdn.com
VITE_LOCALES_URL=https://your-locales.cdn.com

# Logo/Favicon 外链资源地址（可选）
VITE_LOGO_BASE_URL= # Logo 资源外链基地址（不带 theme）
VITE_FAVICON_BASE_URL= # Favicon 资源外链基地址（带 theme）

# Logo 直接 URL（可选，优先级高于 BASE_URL）
VITE_LOGO_FULL_URL= # Header/页面 Logo 完整 URL
VITE_LOGO_PWA_URL= # 旧 UI 品牌图完整 URL（不参与 manifest 图标生成）
VITE_LOGO_LOADER_URL= # 启动页 Loader Logo 完整 URL

# Favicon 直接 URL（可选，优先级高于 BASE_URL）
VITE_FAVICON_PNG_URL= # favicon-192x192 完整 URL
VITE_FAVICON_SVG_URL= # favicon.svg 完整 URL
VITE_FAVICON_ICO_URL= # favicon.ico 完整 URL
VITE_FAVICON_APPLE_URL= # apple-touch-icon 完整 URL

VITE_THEME=yourbrand
VITE_THEME_CONFIG='{"currentTheme":"dark","customOverrides":{"colors":{"primary":"oklch(80% 0.2 50)"}}}'

VITE_WEBSITE_URL=https://www.yourbrand.com
VITE_WEBSITE_NAME_BLOCK=YOUR.BRAND
VITE_WEBSITE_NICKNAME=yourbrand
VITE_WEBSITE_NICKNAME_LEFT=YOUR
VITE_WEBSITE_NICKNAME_RIGHT=.BRAND

VITE_FACEBOOK_PIXEL_ID=
VITE_PROMOTION_MODEL=
VITE_FOLDER=

# Casino 联盟合作模块是否隐藏
VITE_HIDE_ALLIANCE_PARTNERSHIPS=false

# Hero 插画（可选，空则使用默认图）
VITE_BONUS_HERO_IMAGE= # Bonus 页 Hero 插画
VITE_REFERRAL_HERO_IMAGE= # Referral 页 Hero 插画
VITE_TOURNAMENT_HERO_IMAGE= # Tournament 页 Hero 插画
VITE_VIP_HERO_AUTH_CHARACTER_IMAGE= # VIP 已登录 Hero 插画

# Casino 未登录 Banner 插画（可选）
VITE_CASINO_UNAUTH_BANNER_IMAGE_DESKTOP_URL= # 桌面端插画完整 URL
VITE_CASINO_UNAUTH_BANNER_IMAGE_MOBILE_URL= # 移动端插画完整 URL

# SEO 配置（可选）
VITE_SEO_TITLE= # 页面标题
VITE_SEO_DESCRIPTION= # 页面描述
VITE_SEO_OG_TITLE= # Open Graph 标题
VITE_SEO_OG_DESCRIPTION= # Open Graph 描述
VITE_SEO_OG_IMAGE= # Open Graph 图片地址
VITE_SEO_OG_IMAGE_WIDTH= # Open Graph 图片宽度
VITE_SEO_OG_IMAGE_HEIGHT= # Open Graph 图片高度
VITE_SEO_OG_SITE_NAME= # Open Graph 站点名

# PWA 配置（可选）
VITE_PWA_NAME= # PWA 应用名称
VITE_PWA_SHORT_NAME= # PWA 短名称
VITE_PWA_DESCRIPTION= # PWA 描述
VITE_PWA_THEME_COLOR= # PWA 主题色
VITE_PWA_BACKGROUND_COLOR= # PWA 背景色
VITE_PWA_STATUS_BAR_STYLE= # iOS 状态栏样式
VITE_PWA_START_URL= # PWA 启动路径
VITE_PWA_SCOPE= # PWA scope
VITE_PWA_ID= # PWA manifest id
VITE_PWA_ICON_192_URL= # PWA 192 图标 URL
VITE_PWA_ICON_512_URL= # PWA 512 图标 URL
VITE_PWA_MASKABLE_ICON_192_URL= # PWA 192 maskable 图标 URL
VITE_PWA_MASKABLE_ICON_512_URL= # PWA 512 maskable 图标 URL
VITE_PWA_APPLE_ICON_URL= # PWA apple touch 图标 URL
```

说明：
- `VITE_THEME` 对应 `public/logos/<theme>/` 与主题配置。
- `VITE_THEME_CONFIG` 可覆盖主题颜色（详情见 `docs/03-主题配置指南.md`）。
- `VITE_WEBSITE_*` 决定站点标题、昵称和品牌文字。

## 二、准备品牌资源

1. **Logo 与 PWA 图标**
    - 默认放置在 `public/logos/<VITE_THEME>/` 下。
    - 常用文件：`logo-full.svg`、`logo-pwa.png` 等。
    - 如需外链：
      - 用 `VITE_LOGO_BASE_URL` 时默认读取 `/logos/logo-full.svg`、`/logos/logo-pwa.png`（不带 theme）。
      - 用 `VITE_LOGO_FULL_URL` / `VITE_LOGO_PWA_URL` / `VITE_LOGO_LOADER_URL` 可直接指定完整 URL。
      - `VITE_LOGO_PWA_URL` 仅用于旧 UI 品牌图占位，不再作为新 PWA manifest 图标来源。

2. **站点插画与图片**
    - 尽量使用 `public/images/` 统一管理。
    - 若有品牌化插画，替换对应路径即可。
    - 可通过环境变量覆盖 Hero 插画：`VITE_BONUS_HERO_IMAGE`、`VITE_REFERRAL_HERO_IMAGE`、`VITE_TOURNAMENT_HERO_IMAGE`、`VITE_VIP_HERO_AUTH_CHARACTER_IMAGE`。

3. **Favicon 资源**
    - 默认从 `public/favicon/<VITE_THEME>/` 加载。
    - 如需外链：
      - `VITE_FAVICON_BASE_URL` 会拼 `/favicon/<VITE_THEME>/...`。
      - 若你只有单文件 URL，可用 `VITE_FAVICON_PNG_URL` / `VITE_FAVICON_SVG_URL` / `VITE_FAVICON_ICO_URL` / `VITE_FAVICON_APPLE_URL` 直接指定。
      - PWA manifest 图标优先读取 `VITE_PWA_ICON_192_URL` / `VITE_PWA_ICON_512_URL` / `VITE_PWA_MASKABLE_ICON_192_URL` / `VITE_PWA_MASKABLE_ICON_512_URL` / `VITE_PWA_APPLE_ICON_URL`。

4. **PWA 入口与图标**
   - `VITE_PWA_START_URL`、`VITE_PWA_SCOPE`、`VITE_PWA_ID` 控制 manifest 的入口与作用域。
   - `VITE_PWA_APPLE_ICON_URL` 是新的 apple touch icon 主配置；`VITE_FAVICON_APPLE_URL` 保留为站点 head 图标兼容配置。
   - 多品牌接入时，优先补齐 `VITE_PWA_*` 这组变量，而不是继续复用 `VITE_LOGO_PWA_URL`。

3. **主题配置**
   - 如需完整主题包，更新 `public/theme-config.json` 或通过 `VITE_THEME_CONFIG` 覆盖。

## 三、文案与国际化

1. **基础文案**
   - 主要文案在 `public/locales/` 下。
   - 若使用外部语言包，确保 `VITE_LOCALES_URL` 指向正确地址。

2. **品牌名替换**
   - 注意 `VITE_WEBSITE_NICKNAME` 与 `VITE_WEBSITE_NAME_BLOCK` 的统一性。
   - 若有硬编码品牌名，请在对应组件中替换或改为变量。

## 四、功能开关（可选）

部分模块可通过环境变量控制显示：

- `VITE_HIDE_ALLIANCE_PARTNERSHIPS`: 控制 Casino 页面“联盟合作”模块隐藏（默认显示）。

## 五、构建与部署

```bash
pnpm install
pnpm build
pnpm serve
```

检查项：
- Logo、PWA 图标是否替换成功
- 主题颜色与按钮/背景是否符合品牌
- 文案是否已替换为新品牌
- 主要页面（首页、登录、注册、Casino）是否正常

## 六、快速排查

- Logo 不显示：确认 `VITE_THEME` 与 `public/logos/<theme>` 路径一致。
- 文案未更新：确认是否有外部语言包覆盖（`VITE_LOCALES_URL`）。
- 主题未生效：检查 `VITE_THEME_CONFIG` 格式或 `public/theme-config.json`。
