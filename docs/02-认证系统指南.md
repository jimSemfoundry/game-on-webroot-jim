# 认证系统实现指南

## 🏗️ 架构概述

基于 TanStack Router 官方最佳实践实现的完整认证系统。

### 核心组件

1. **AuthContext** (`src/contexts/AuthContext.tsx`) - 认证状态管理
2. **Auth Guards** (`src/lib/auth-guards.ts`) - 路由保护工具（✅ 使用 Router Context）
3. **Layout Routes** - 批量路由保护（`_main/_authenticated`）
4. **Router Context** (`src/routes/__root.tsx`) - 认证状态传递到路由层

## 🔒 路由保护模式

### 模式 1：完全保护的页面（推荐）⭐️

使用 `_main/_authenticated` 布局路由自动保护所有子路由：

```typescript
// routes/_main/_authenticated/profile.tsx
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/_main/_authenticated/profile')({
  component: ProfilePage,
});

function ProfilePage() {
  return (
    <div>
      <h1>用户资料</h1>
    </div>
  );
}
```

**工作原理**：
- `_main/_authenticated.tsx` 中使用 `requireAuth` 守卫
- 守卫从 **Router Context** 读取认证状态（不是 localStorage）
- 所有 `_authenticated/` 下的路由自动受保护

**优点**：
- ✅ 所有 `_main/_authenticated/` 下的路由自动受保护
- ✅ 无需在每个路由重复认证逻辑
- ✅ 统一的认证处理
- ✅ 类型安全的认证状态

### 模式 2：公开页面 + 条件内容

页面可公开访问，但部分内容需要认证：

```typescript
// routes/casino/index.tsx
import { createFileRoute } from '@tanstack/react-router';
import { useAuth } from '@/contexts/AuthContext';

export const Route = createFileRoute('/casino/')({
  component: CasinoPage,
});

function CasinoPage() {
  const { isAuthenticated, user } = useAuth();
  
  return (
    <div>
      <h1>赌场游戏</h1>
      
      {/* 公开内容 */}
      <PublicGameList />
      
      {/* 认证后才显示 */}
      {isAuthenticated ? (
        <div>
          <h2>欢迎回来，{user?.username}！</h2>
          <UserFavoriteGames />
          <UserStats />
        </div>
      ) : (
        <div>
          <p>登录以查看您的收藏和统计</p>
          <LoginPrompt />
        </div>
      )}
    </div>
  );
}
```

### 模式 3：单独路由保护

特定路由需要保护，但不在 `_authenticated/` 目录下：

```typescript
// routes/special-feature.tsx
import { createFileRoute, redirect } from '@tanstack/react-router';

export const Route = createFileRoute('/special-feature')({
  beforeLoad: async ({ context, location }) => {
    if (!context.auth.isAuthenticated) {
      throw redirect({
        to: '/',
        search: { redirect: location.href },
      });
    }
  },
  component: SpecialFeaturePage,
});
```

### 模式 4：角色基础保护

基于用户角色保护路由：

```typescript
// routes/admin.tsx
import { createFileRoute, redirect } from '@tanstack/react-router';

export const Route = createFileRoute('/admin')({
  beforeLoad: async ({ context, location }) => {
    const { isAuthenticated, user } = context.auth;
    
    if (!isAuthenticated) {
      throw redirect({ to: '/', search: { redirect: location.href } });
    }
    
    if (!user?.roles?.includes('admin')) {
      throw redirect({ to: '/', search: { error: 'unauthorized' } });
    }
  },
  component: AdminPage,
});
```

## 🚀 使用方式

### 在组件中使用认证状态

```typescript
import { useAuth } from '@/contexts/AuthContext';

function MyComponent() {
  const { 
    isAuthenticated,  // 是否已认证
    user,             // 用户信息
    login,            // 登录函数
    logout,           // 登出函数
    isLoading,        // 加载状态
  } = useAuth();
  
  if (isLoading) {
    return <LoadingSpinner />;
  }
  
  return (
    <div>
      {isAuthenticated ? (
        <div>
          <p>欢迎，{user?.username}</p>
          <button onClick={logout}>登出</button>
        </div>
      ) : (
        <div>
          <p>请先登录</p>
          <button onClick={() => login(credentials)}>登录</button>
        </div>
      )}
    </div>
  );
}
```

## 🔄 认证流程

### 登录流程

```mermaid
用户访问应用
    ↓
检查 localStorage 是否有 token
    ↓
有 token → 验证 token 有效性
    ↓
有效 → 自动登录，获取用户信息
    ↓
无效 → 清除 token，显示登录界面
```

1. 用户打开应用
2. `AuthContext` 初始化，从 `localStorage` 读取 token
3. 如果有 token，自动验证并获取用户信息
4. 验证成功，设置 `isAuthenticated = true`
5. 用户可以访问受保护的内容

### 受保护路由访问流程

```mermaid
用户访问受保护页面
    ↓
beforeLoad 检查认证状态
    ↓
已认证？
  是 → 正常加载页面
  否 → 重定向到首页，附带 redirect 参数
    ↓
用户在首页看到登录提示
    ↓
登录成功后重定向回原始页面
```

### 登出流程

```mermaid
用户点击登出
    ↓
调用 logout() 函数
    ↓
清除 localStorage 中的 token
    ↓
清除用户状态
    ↓
设置 isAuthenticated = false
    ↓
Router 自动重定向（因为失去认证状态）
```

修改 `src/routes/_authenticated.tsx`：

```typescript
export const Route = createFileRoute('/_authenticated')({

    const { isAuthenticated, user } = context.auth;

        search: { error: 'account_suspended' },
      });
    }
  },
  component: AuthenticatedLayout,

```

### Token 自动刷新

在 `src/lib/authAxios.ts` 中已实现：

```typescript
authAxiosInstance.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;
    
    if (error.response?.status === 401) {
      originalRequest._retryCount = originalRequest._retryCount || 0;
      originalRequest._retryCount++;
      
      if (originalRequest._retryCount >= 3) {
        clearAuth('multiple_401_errors');
        return Promise.reject(error);
      }
      
      try {
        const auth = getAuth();
        if (auth) {
          originalRequest.headers.auth = JSON.stringify(auth);
          return authAxiosInstance(originalRequest);
        }
      } catch (authError) {
        clearAuth('auth_generation_failed');
      }
    }
    
    return Promise.reject(error);
  }
);
```

## 🛡️ 安全最佳实践

### 1. Token 存储

**当前实现**：使用 `localStorage` 存储认证信息

```typescript
// src/utils/auth.ts
export function saveAuth(authData: AuthData) {
  const key = generateAuthKey();
  localStorage.setItem(key, JSON.stringify(authData));
}

export function getAuth(): AuthData | null {
  const key = generateAuthKey();
  const stored = localStorage.getItem(key);
  return stored ? JSON.parse(stored) : null;
}
```

**生产环境建议**：
- 使用 `httpOnly` cookies 存储敏感 token
- 实现 CSRF 保护
- 使用短期 access token + 长期 refresh token

### 2. Token 验证

每次应用启动都验证 token：

```typescript
useEffect(() => {
  const initAuth = async () => {
    const auth = getAuth();
    if (auth) {
      try {
        const userData = await authService.verifyToken();
        setUser(userData);
        setIsAuthenticated(true);
      } catch (error) {
        clearAuth('invalid_token');
      }
    }
    setIsLoading(false);
  };
  
  initAuth();
}, []);
```

### 3. 自动登出

Token 过期或无效时自动清除：

```typescript
export function clearAuth(reason?: string) {
  if (reason) {
    console.log('Clearing auth:', reason);
  }
  
  const key = generateAuthKey();
  localStorage.removeItem(key);
  
  window.location.href = '/';
}
```

### 4. 路由级保护

始终在路由层面保护，而非仅在组件层面：

```typescript
// ✅ 正确：路由级保护
export const Route = createFileRoute('/_authenticated/profile')({
  component: ProfilePage,
});

// ❌ 错误：仅组件级保护
export const Route = createFileRoute('/profile')({
  component: ProfilePage,
});

function ProfilePage() {
  const { isAuthenticated } = useAuth();
  if (!isAuthenticated) return <Redirect to="/" />;
  
  return <div>Profile</div>;
}
```

使用 TypeScript 确保类型安全：

## 🐛 常见问题

### Q1: 如何在 beforeLoad 中获取用户信息？

**A**: 使用 `context.auth`，不要使用 `useAuth()` hook（hooks 只能在组件中使用）。

```typescript
export const Route = createFileRoute('/my-route')({
  beforeLoad: ({ context }) => {
    const { isAuthenticated, user } = context.auth;
    console.log('User:', user);
  },
});
```

### Q2: 登录后页面没有更新？

**A**: 确保：
1. `AuthProvider` 包装了整个应用（在 `__root.tsx`）
2. 状态正确传递到 Router context
3. 组件使用 `useAuth()` 获取最新状态

### Q3: 如何处理 Token 过期？

**A**: 在 `authAxios` 拦截器中已处理：

```typescript
if (error.response?.status === 401) {
  // 尝试重新生成认证信息
  // 失败 3 次后自动清除认证状态
  clearAuth('token_expired');
}
```

### Q4: 部分内容需要认证的页面如何处理？

**A**: 不要放在 `_authenticated` 目录下，在组件内部使用条件渲染：

```typescript
function CasinoPage() {
  const { isAuthenticated } = useAuth();
  
  return (
    <div>
      <PublicContent />
      {isAuthenticated && <PrivateContent />}
    </div>
  );
}
```

### Q5: 如何实现"记住我"功能？

**A**: 修改 token 存储逻辑：

```typescript
export function saveAuth(authData: AuthData, rememberMe: boolean = false) {
  const storage = rememberMe ? localStorage : sessionStorage;
  const key = generateAuthKey();
  storage.setItem(key, JSON.stringify(authData));
}
```

### Q6: 多标签页登出同步？

**A**: 使用 `storage` 事件监听：

```typescript
useEffect(() => {
  const handleStorageChange = (e: StorageEvent) => {
    if (e.key?.includes('auth') && !e.newValue) {
      setIsAuthenticated(false);
      setUser(null);
    }
  };
  
  window.addEventListener('storage', handleStorageChange);
  return () => window.removeEventListener('storage', handleStorageChange);
}, []);
```
