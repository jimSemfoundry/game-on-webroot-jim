## 图标系统概述

项目使用自定义的图标构建系统，工作流程如下：

```mermaid
添加 SVG → 构建图标 → 自动注册 → 在组件中使用
  ↓           ↓           ↓           ↓
svg/      icons:build   iconify    <Icon />
```

### 核心文件

```
src/assets/icons/
├── svg/                          # 📁 SVG 源文件目录（你需要添加图标到这里）
│   ├── arcade.svg
│   ├── casino.svg
│   ├── wallet.svg
│   └── ...                       # 104 个 SVG 文件
├── icons.json                    # 🔧 自动生成的图标数据（不要手动编辑）
└── logo-full.svg                 # 项目 Logo

src/components/iconify/
└── register-icons.ts             # 🎯 自动注册图标到 Iconify

scripts/
└── build-icons.cjs               # 🛠️ 图标构建脚本
```

### 工作原理

1. **添加 SVG**：将 SVG 文件放入 `src/assets/icons/svg/` 目录
2. **构建图标**：运行 `pnpm icons:build` 生成 `icons.json`
3. **自动注册**：应用启动时自动注册所有图标
4. **使用图标**：通过 `<Icon icon="custom:图标名" />` 使用

## 添加新图标

### 步骤 1: 准备 SVG 文件

将 SVG 文件添加到 `src/assets/icons/svg/` 目录。

**文件命名规范**：
- ✅ 使用 kebab-case（短横线命名）
- ✅ 只包含小写字母、数字和短横线
- ✅ 文件名即图标名

```bash
# ✅ 正确
arcade.svg
bonus-wheel.svg
vip-crown.svg

# ❌ 错误
Arcade.svg          # 不要大写
bonus_wheel.svg     # 不要下划线
vip crown.svg       # 不要空格
```

### 步骤 2: 检查 SVG 内容

确保 SVG 文件包含必要的属性：

```xml
<svg width="24" height="24" viewBox="0 0 24 24" fill="none" xmlns="http://www.w3.org/2000/svg">
  <path d="M12 2L2 7L12 12L22 7L12 2Z" fill="currentColor"/>
  <path d="M2 17L12 22L22 17" stroke="currentColor" stroke-width="2"/>
</svg>
```

**必需属性**：
- `viewBox` - 定义图标的坐标系统和尺寸
- `fill` 或 `stroke` - 使用 `currentColor` 以支持主题颜色

## 处理 Figma SVG

### 问题：Figma 导出的 SVG 包含硬编码颜色

从 Figma 复制或导出的 SVG 通常包含固定颜色值：

```xml
<!-- ❌ Figma 原始 SVG - 颜色固定，无法随主题变化 -->
<svg viewBox="0 0 24 24">
  <path d="..." fill="#1E293B"/>
  <path d="..." stroke="#64748B"/>
  <circle cx="12" cy="12" r="4" fill="rgb(59, 130, 246)"/>
</svg>
```

这会导致：
- ❌ 图标颜色无法随主题切换
- ❌ 无法通过 CSS 控制颜色
- ❌ 深色/浅色主题下显示不正确

### 解决方案：替换为 currentColor

将所有固定颜色替换为 `currentColor`：

```xml
<!-- ✅ 修改后的 SVG - 颜色可控 -->
<svg viewBox="0 0 24 24">
  <path d="..." fill="currentColor"/>
  <path d="..." stroke="currentColor"/>
  <circle cx="12" cy="12" r="4" fill="currentColor"/>
</svg>
```

### 手动替换方法

1. 打开 SVG 文件
2. 查找替换：
   - `fill="#任何颜色"` → `fill="currentColor"`
   - `stroke="#任何颜色"` → `stroke="currentColor"`
   - `fill="rgb(...)"` → `fill="currentColor"`

3. 删除不必要的属性：
   - `fill-opacity`
   - `stroke-opacity`
   - 多余的 `xmlns` 声明

### 批量替换脚本

如果需要处理多个 SVG 文件，使用以下脚本：

```javascript
// replace-colors.js
const fs = require('fs');
const path = require('path');

const SVG_DIR = 'src/assets/icons/svg';

function processSVG(filePath) {
  let svg = fs.readFileSync(filePath, 'utf8');
  
  // 替换 fill 颜色
  svg = svg.replace(/fill="#[0-9A-Fa-f]{3,6}"/g, 'fill="currentColor"');
  svg = svg.replace(/fill='#[0-9A-Fa-f]{3,6}'/g, 'fill="currentColor"');
  svg = svg.replace(/fill="rgb\([^)]+\)"/g, 'fill="currentColor"');
  svg = svg.replace(/fill="rgba\([^)]+\)"/g, 'fill="currentColor"');
  
  // 替换 stroke 颜色
  svg = svg.replace(/stroke="#[0-9A-Fa-f]{3,6}"/g, 'stroke="currentColor"');
  svg = svg.replace(/stroke='#[0-9A-Fa-f]{3,6}'/g, 'stroke="currentColor"');
  svg = svg.replace(/stroke="rgb\([^)]+\)"/g, 'stroke="currentColor"');
  
  // 删除透明度属性
  svg = svg.replace(/fill-opacity="[^"]*"/g, '');
  svg = svg.replace(/stroke-opacity="[^"]*"/g, '');
  
  fs.writeFileSync(filePath, svg, 'utf8');
  console.log(`✅ Processed: ${path.basename(filePath)}`);
}

// 处理所有 SVG 文件
fs.readdirSync(SVG_DIR)
  .filter(file => file.endsWith('.svg'))
  .forEach(file => processSVG(path.join(SVG_DIR, file)));

console.log('🎉 All files processed!');
```

运行脚本：

```bash
node replace-colors.js
```

### 特殊情况：保留部分颜色

如果某些图标需要保留特定颜色（如多色图标），可以选择性替换：

```xml
<!-- 部分使用 currentColor，部分保留固定颜色 -->
<svg viewBox="0 0 24 24">
  <!-- 主体颜色可控 -->
  <path d="..." fill="currentColor"/>
  
  <!-- 特定装饰保留颜色 -->
  <circle cx="12" cy="12" r="2" fill="#FFD700"/>
</svg>
```

## 构建图标

### 运行构建命令

添加或修改 SVG 文件后，运行构建命令：

```bash
pnpm icons:build
```

### 构建过程

脚本会自动执行以下操作：

1. **扫描 SVG 目录**：读取 `src/assets/icons/svg/` 中的所有 `.svg` 文件

2. **提取图标数据**：
   - 文件名（去掉 `.svg` 后缀）
   - `viewBox` 属性
   - 宽度和高度
   - SVG 内容（去掉外层 `<svg>` 标签）

3. **生成 icons.json**：
   ```json
   {
     "prefix": "custom",
     "icons": {
       "arcade": {
         "body": "<path d='...' fill='currentColor'/>",
         "width": 14,
         "height": 14,
         "viewBox": "0 0 14 14"
       },
       "casino": {
         "body": "<path d='...' fill='currentColor'/>",
         "width": 20,
         "height": 20,
         "viewBox": "0 0 20 20"
       }
     }
   }
   ```

4. **输出构建信息**：
   ```
   🔍 Found 104 SVG file(s):
      ✅ arcade (14x14, 245 chars)
      ✅ casino (20x20, 312 chars)
      ✅ wallet (24x24, 189 chars)
      ...
   📏 All icons have common dimensions: 20x20 (0 0 20 20)
   🎉 Generated src/assets/icons/icons.json with 104 icons!
   ```

### 构建脚本详解

构建脚本 (`scripts/build-icons.cjs`) 的关键配置：

```javascript
const SVG_DIR = 'src/assets/icons/svg';           // SVG 源文件目录
const OUTPUT_FILE = 'src/assets/icons/icons.json'; // 输出文件

// 注意：脚本不会自动替换颜色为 currentColor
// 需要在添加 SVG 前手动处理颜色
```

**重要提示**：
- ⚠️ 脚本**不会**自动将颜色替换为 `currentColor`
- ⚠️ 需要在添加 SVG 文件前手动处理颜色
- ⚠️ `icons.json` 是自动生成的，不要手动编辑

## 使用图标

### 基本用法

图标会在应用启动时自动注册（通过 `src/components/iconify/register-icons.ts`）。

```tsx
import { Icon } from '@iconify/react';

function MyComponent() {
  return (
    <div>
      {/* 使用格式: custom:文件名(不含.svg) */}
      <Icon icon="custom:casino" />
      <Icon icon="custom:wallet" />
      <Icon icon="custom:arcade" />
    </div>
  );
}
```

**命名规则**：
- 前缀：`custom:`（项目自定义图标的命名空间）
- 图标名：SVG 文件名（不含 `.svg` 后缀）

### 调整图标大小

```tsx
<Icon icon="custom:casino" width="16" height="16" />

<Icon icon="custom:wallet" width={24} height={24} />

<Icon icon="custom:arcade" className="w-8 h-8" />
```

### 图标颜色

图标颜色通过 CSS 的 `color` 属性控制（因为使用了 `currentColor`）。

使用 Tailwind 文本颜色类：

```tsx
<Icon icon="custom:casino" className="text-primary" />

<Icon icon="custom:wallet" className="text-success" />

<Icon icon="custom:arcade" className="text-error" />
```

### 完整示例

```tsx
import { Icon } from '@iconify/react';

function GameCard({ game }) {
  return (
    <div className="card bg-base-100 shadow-xl">
      <figure className="p-4">
        <Icon 
          icon={`custom:${game.type}`}
          className="w-16 h-16 text-primary"
        />
      </figure>
      
      <div className="card-body">
        <h2 className="card-title">
          {game.name}
          {game.isNew && (
            <Icon icon="custom:new" className="w-5 h-5 text-success" />
          )}
          {game.isHot && (
            <Icon icon="custom:hot" className="w-5 h-5 text-error" />
          )}
        </h2>
        
        <div className="card-actions justify-end">
          <button className="btn btn-primary">
            <Icon icon="custom:play" className="w-5 h-5" />
            <span>开始游戏</span>
          </button>
        </div>
      </div>
    </div>
  );
}
```

## 最佳实践

### 1. 统一图标尺寸

定义标准尺寸常量：

```typescript
// src/constants/ui.ts
export const ICON_SIZES = {
  xs: { width: 12, height: 12 },
  sm: { width: 16, height: 16 },
  md: { width: 20, height: 20 },
  lg: { width: 24, height: 24 },
  xl: { width: 32, height: 32 },
} as const;
```

使用：

```tsx
import { ICON_SIZES } from '@/constants/ui';

<Icon icon="custom:casino" {...ICON_SIZES.lg} />
```

### 2. 创建图标包装组件

```tsx
// src/components/ui/CustomIcon.tsx
import { Icon } from '@iconify/react';
import { cn } from '@/lib/utils';

interface CustomIconProps {
  name: string;
  size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl';
  className?: string;
}

const sizeClasses = {
  xs: 'w-3 h-3',
  sm: 'w-4 h-4',
  md: 'w-5 h-5',
  lg: 'w-6 h-6',
  xl: 'w-8 h-8',
};

export function CustomIcon({ name, size = 'md', className }: CustomIconProps) {
  return (
    <Icon
      icon={`custom:${name}`}
      className={cn(sizeClasses[size], className)}
    />
  );
}
```

使用：

```tsx
<CustomIcon name="casino" size="lg" className="text-primary" />
```

### 3. 图标 + 文本组合

### 5. 动态图标名称

```tsx
function GameTypeIcon({ type }: { type: string }) {
```

## 常见问题

### Q1: 添加新图标后不显示？

**A**: 确保已运行构建命令并重启开发服务器：

```bash
pnpm icons:build

pnpm dev
```

### Q2: 图标颜色无法改变？

**A**: 检查 SVG 文件是否使用了 `currentColor`：

```xml
<!-- ❌ 错误 -->
<path fill="#000000" />

<!-- ✅ 正确 -->
<path fill="currentColor" />
```

### Q3: 图标名称不正确？

**A**: 图标名称就是 SVG 文件名（不含 `.svg`）：

```
文件: bonus-wheel.svg
使用: custom:bonus-wheel

文件: vip-crown.svg
使用: custom:vip-crown
```

### Q4: 如何查看所有可用图标？

**A**: 查看 `src/assets/icons/svg/` 目录或 `icons.json` 文件：

```bash
ls src/assets/icons/svg/

cat src/assets/icons/icons.json | grep '"' | head -20
```

### Q5: icons.json 文件丢失？

**A**: 重新运行构建命令：

```bash
pnpm icons:build
```

### Q6: 图标尺寸不一致？

**A**: 统一设置图标尺寸：

```tsx
<Icon icon="custom:casino" width={24} height={24} />

<Icon icon="custom:wallet" className="w-6 h-6" />
```

### Q7: 如何批量替换颜色？

**A**: 使用前面提供的批量替换脚本，或使用编辑器的查找替换功能：

- 查找：`fill="#[0-9A-Fa-f]{6}"`
- 替换：`fill="currentColor"`

### Q8: 图标在深色主题下看不见？

**A**: 确保使用了 Tailwind 的颜色类，而不是固定颜色：

```tsx
<Icon icon="custom:menu" className="text-base-content" />
```

### Q9: 如何创建图标变体？

**A**: 使用不同的颜色类创建变体：

```tsx
<Icon icon="custom:heart" className="text-error" />

<Icon icon="custom:heart" className="text-error fill-error" />

<Icon icon="custom:heart" className="text-base-content/30" />
```

### Q10: 图标在生产环境不显示？

**A**: 确保：
1. `icons.json` 已提交到代码库
2. `register-icons.ts` 在应用启动时执行
3. 构建时没有报错

## 开发工作流

### 完整的图标添加流程

```bash
# 1. 从 Figma 导出或复制 SVG
# 2. 手动替换颜色为 currentColor（如果需要）
# 3. 将 SVG 文件放入 svg 目录
cp my-icon.svg src/assets/icons/svg/

# 4. 构建图标
pnpm icons:build

# 5. 重启开发服务器（如果正在运行）
# Ctrl+C
pnpm dev

# 6. 在代码中使用
# <Icon icon="custom:my-icon" />
```

### 检查清单

添加新图标前确认：

- [ ] SVG 文件名使用 kebab-case
- [ ] SVG 包含 `viewBox` 属性
- [ ] 颜色使用 `currentColor`（如果需要主题适配）
- [ ] 删除了不必要的属性和注释
- [ ] 运行了 `pnpm icons:build`
- [ ] 测试了不同主题下的显示效果
