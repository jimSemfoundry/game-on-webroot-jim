## 配置方法

项目支持两种主题配置方式：

### 方式 1：运行时配置文件（推荐）

通过 `public/theme-config.json` 文件配置，支持运行时热更新。

**优点**：
- ✅ 无需重新构建和部署
- ✅ 支持热重载（30 秒轮询）
- ✅ 可通过 Cloudflare Workers KV 动态更新
- ✅ 用户体验更好（无闪烁）

**配置位置**：`public/theme-config.json`

```json
{
  "currentTheme": "business",
  "brandConfig": {
    "brandName": "GAME.ON",
    "version": "1.0.0",
    "lastUpdated": "2024-01-15T10:30:00Z"
  }
}
```

### 方式 2：构建时环境变量

通过 Cloudflare Pages 的构建环境变量配置。

**优点**：
- ✅ 构建时注入，确保首次加载无闪烁
- ✅ 适合固定主题的场景

**缺点**：
- ❌ 需要重新构建才能更改
- ❌ 更新周期长

## 环境变量

### 在 Cloudflare Pages 中配置

1. 登录 Cloudflare Dashboard
2. 进入您的 Pages 项目
3. 进入 **Settings** → **Environment variables**
4. 添加构建环境变量：

**变量名**: `VITE_THEME_CONFIG`

**值**（必须是单行 JSON）:

```json
{"currentTheme":"business","customOverrides":{"colors":{"primary":"#570df8"}},"brandConfig":{"brandName":"我的品牌","version":"2.0.0"}}
```

⚠️ **重要提示**: 环境变量的值必须是单行的、没有换行符的 JSON 字符串。


### 参数详解

#### `currentTheme` (string, 必需)

指定基础主题。系统会先加载这个主题的默认值，然后再应用 `customOverrides` 中的自定义设置。

**可选值**:
- `default` - 默认主题
- `light` - 明亮主题
- `dark` - 暗黑主题
- `business` - 商务主题
- `forest` - 森林主题
- `luxury` - 奢华主题
- `cyberpunk` - 赛博朋克
- `valentine` - 情人节
- `halloween` - 万圣节
- `autumn` - 秋季

```json
{
  "currentTheme": "business"
}
```

#### `customOverrides` (object, 可选)

用于覆盖基础主题的自定义设置。

##### `colors` (object, 可选)

覆盖颜色。您不需要提供所有颜色，只需提供想修改的颜色即可。

**主色系**：
- `primary` - 主色
- `primaryContent` - 主色上的文字颜色
- `secondary` - 辅助色
- `secondaryContent` - 辅助色上的文字颜色
- `accent` - 强调色
- `accentContent` - 强调色上的文字颜色

**中性色**：
- `neutral` - 中性色
- `neutralContent` - 中性色上的文字颜色

**背景色**：
- `base100` - 主背景色
- `base200` - 次背景色
- `base300` - 三级背景色
- `base400` - 四级背景色（最深）
- `baseContent` - 背景上的文字颜色

**状态色**：
- `info` / `infoContent` - 信息提示色
- `success` / `successContent` - 成功色
- `warning` / `warningContent` - 警告色
- `error` / `errorContent` - 错误色

**颜色格式**：支持 HEX、RGB、OKLCH 格式

```json
{
  "customOverrides": {
    "colors": {
      "primary": "#570df8",
      "secondary": "rgb(240, 0, 184)",
      "accent": "oklch(77% 0.15 180)"
    }
  }
}
```

##### 样式参数

- `radiusSelector` (string) - 按钮、选择器的圆角大小
- `radiusField` (string) - 输入框的圆角大小
- `radiusBox` (string) - 卡片、容器的圆角大小
- `sizeSelector` (string) - 选择器的大小
- `sizeField` (string) - 输入框的大小
- `border` (string) - 全局边框宽度
- `fontFamily` (string) - 全局字体
- `noise` (number, 0-1) - 背景噪点效果强度
- `depth` (number, 0-1) - 元素的阴影/深度效果

```json
{
  "customOverrides": {
    "radiusSelector": "0.5rem",
    "radiusField": "0.25rem",
    "radiusBox": "1rem",
    "border": "2px",
    "fontFamily": "Inter, sans-serif",
    "noise": 0.15,
    "depth": 0.5
  }
}
```

#### `brandConfig` (object, 可选)

用于在主题选择器中显示品牌信息，对主题样式无影响。

- `brandName` (string) - 品牌名称
- `version` (string) - 主题版本号
- `lastUpdated` (string) - 最后更新时间（ISO 格式）

```json
{
  "brandConfig": {
    "brandName": "GAME.ON",
    "version": "1.0.0",
    "lastUpdated": "2024-01-15T10:30:00Z"
  }
}
```

## 运行时主题切换

### 在组件中切换主题

```typescript
import { useTheme } from '@/contexts/ThemeContext';

function ThemeSwitcher() {
  const { currentTheme, setTheme, availableThemes } = useTheme();

  return (
    <select 
      value={currentTheme} 
      onChange={(e) => setTheme(e.target.value)}
      className="select select-bordered"
    >
      {availableThemes.map((theme) => (
        <option key={theme} value={theme}>
          {theme}
        </option>
      ))}
    </select>
  );
}
```

## Cloudflare 部署配置

### 使用 Cloudflare Workers + KV 动态更新主题

项目支持通过 Cloudflare Workers 和 KV 存储动态更新主题配置。

#### 步骤 1: 更新主题配置

```bash
# 更新 public/theme-config.json
pnpm theme:update
```

#### 步骤 2: 部署到 Cloudflare Workers

```bash
# 部署 Worker
pnpm theme:deploy
```

#### 步骤 3: 验证更新

访问您的网站，主题应该在 30 秒内自动更新（轮询间隔）。

### 配置 Wrangler

项目根目录需要有 `wrangler.toml`：

```toml
name = "theme-config-worker"
main = "workers/theme-config.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "THEME_CONFIG"
id = "your_kv_namespace_id"
```

### Worker 代码示例

```javascript
export default {
  async fetch(request, env) {
    const config = await env.THEME_CONFIG.get('config');
    
    return new Response(config || '{}', {
      headers: {
        'Content-Type': 'application/json',
        'Access-Control-Allow-Origin': '*',
        'Cache-Control': 'public, max-age=30',
      },
    });
  },
};
```

## 如何应用修改

### 方法 1：修改配置文件（推荐）

1. 编辑 `public/theme-config.json`
2. 保存文件
3. 如果开发服务器正在运行，主题会自动更新
4. 生产环境：运行 `pnpm theme:update` 和 `pnpm theme:deploy`

### 方法 2：修改环境变量

1. 在文本编辑器中准备您的 JSON 配置
2. 将其压缩为单行（使用在线 JSON minifier）
3. 登录 Cloudflare Dashboard
4. 进入 Pages 项目 → Settings → Environment variables
5. 编辑 `VITE_THEME_CONFIG` 变量
6. 粘贴压缩后的 JSON
7. 保存并触发新的部署

## 常见问题

### Q1: 修改主题后没有生效？

**A**: 检查：
1. JSON 格式是否正确
2. 浏览器缓存（硬刷新：Ctrl+Shift+R / Cmd+Shift+R）
3. 开发服务器是否重启
4. 生产环境是否重新部署

### Q2: 颜色显示不正确？

**A**: 确保：
1. 颜色格式正确（HEX、RGB 或 OKLCH）
2. `Content` 颜色与对应的背景色对比度足够
3. 检查浏览器开发工具中的计算样式

### Q3: 如何测试主题？

**A**: 使用浏览器开发工具：
1. 打开开发者工具（F12）
2. 找到 `<html>` 标签
3. 查看 `data-theme` 属性
4. 手动修改测试不同主题

### Q4: 主题切换有闪烁？

**A**: 
1. 确保主题在构建时注入
2. 使用 `theme-config.json` 配置
3. 避免在运行时动态加载主题

### Q5: 如何创建自己的主题预设？

**A**: 修改 `src/themes/presets.ts`：

```typescript
export const customThemes = {
  myTheme: {
    primary: '#your-color',
    secondary: '#your-color',
    // ... 其他颜色
  },
};
```
